## 🚀 Quick CLI & API Usage

```bash
# 1. Run an instant deterministic benchmark via JSON API
curl -s "https://www.citationforge.io/api/github-upgrade/fuse-search?q=linear.app" | jq .

# 2. Call the Model Context Protocol (MCP) JSON-RPC endpoint directly
curl -s -X POST "https://www.citationforge.io/api/mcp/rpc" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"arguments":{"query":"linear.app"}}}' | jq .
```
